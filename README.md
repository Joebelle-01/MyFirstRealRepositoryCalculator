## Description
This repository contains a simple, interactive Command-Line Interface (CLI) calculator built in Python. It allows users to perform basic mathematical operations including addition, subtraction, multiplication, and division with error handling for division by zero.

---

## How to Run the Program

### Prerequisites
- Python 3.x installed on your computer.

### Steps
1. Clone this repository or download the source files:
   `ash
   git clone <YOUR_REPOSITORY_URL>
   cd calculator-project
   `

2. Run the program using Python:
   `ash
   python calculator.py
   `

3. Follow the on-screen prompts to select an arithmetic operation and input your numbers.
